# Animation Guidelines

## Direction
Bold and expressive motion that still reads as premium and deliberate.

## Principles
- Use motion to stage artwork and guide focus.
- Avoid constant idle animations that distract from paintings.
- Keep transitions snappy and intentional.

## Accessibility
- Respect `prefers-reduced-motion`.
- Ensure motion is never required to access content.

## Initial Implementation Plan
- Add route transition choreography.
- Add reveal staggering for gallery card entry.
- Add subtle parallax/gradient movement on hero zones only.
