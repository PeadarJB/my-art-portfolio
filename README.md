# my-art-portfolio

Modern rebuild of the artist portfolio using Next.js, TypeScript, Zustand, and token-driven design.

## Quick start
1. Install dependencies:
   `npm install`
2. Copy environment file:
   `copy .env.example .env.local`
3. Run development server:
   `npm run dev`

## Stack
- Next.js App Router
- TypeScript (strict)
- Zustand
- Zod
